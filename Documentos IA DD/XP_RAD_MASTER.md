## 1. Prácticas de Ingeniería Ágil Aplicadas

* **Integración Continua Local (CI Loop):** Todo cambio en el código fuente debe validar automáticamente que `npm test` pase al 100% y que `npm run build` genere el bundle sin advertencias críticas antes de realizar cualquier commit.
* **Refactorización Segura:** Las mejoras en la orquestación de IA se prueban contra fixtures de red simulada en milisegundos, evitando dependencias externas frágiles.
* **Prototipado Rápido (RAD):** Componentes aislados se diseñan con feedback visual inmediato usando TailwindCSS-free Vanilla CSS tokens para máxima velocidad y control.
