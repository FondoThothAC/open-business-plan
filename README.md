# Open Plan React v7.0 (MexiTaco Edition)

![React](https://img.shields.io/badge/React-18-blue?style=for-the-badge&logo=react)
![Vite](https://img.shields.io/badge/Vite-5-646CFF?style=for-the-badge&logo=vite)

Open Plan React es la versión más reciente y modular de nuestra plataforma de arquitectura de negocios. Diseñada para startups modernas que necesitan pasar de la idea a la ejecución en tiempo récord.

## 🚀 Lo nuevo en v7.0
- **Estructura React Pura**: Componentes modulares y reutilizables.
- **Vite Architecture**: Arranque y recarga instantánea.
- **Examples Engine**: Incluye casos de éxito como **MexiTaco Europe**.
- **Lean Startup Tools**: Módulos específicos para Lean Canvas y Pitch Deck.
